# runomine

Cookieless analytics that counts money, not just visits. Your backend sends pageviews, signups and purchases straight
to [runomine.com](https://runomine.com). The visitor hash is computed on your server, so the IP never leaves it and no
cookie is set. Revenue comes from your payment provider (Stripe, Paddle, Lemon Squeezy, Shopify, PayPal), not from
prices in your code.

| | |
|---|---|
| [cli](https://github.com/runomine/cli) | `runomine init` sets up a project in one command; read your numbers from the terminal; MCP for your agent |
| [runomine-php](https://github.com/runomine/runomine-php) | PHP and Laravel |
| [runomine-node](https://github.com/runomine/runomine-node) | Node: Express, Next.js, Fetch API |
| [runomine-python](https://github.com/runomine/runomine-python) | Python: Django, FastAPI, Flask |
| [runomine-rust](https://github.com/runomine/runomine-rust) | Rust: axum, tower, actix-web |
